# RAG 調整紀錄（第四章 4.9）

測試集：`data/eval/testset.json`，共 26 題（20 題應回答並標註應命中的條文、6 題應拒答或轉介）。
指標說明：
- **前 5 段命中率**：應命中的條文是否出現在 BM25（或混合檢索）排名前 5 段。
- **含問答引用命中率**：再加上「被排名前面的常見問答所引用、自動附上的條文原文」（最多 4 段）。

以下數據皆為 `npm run eval -- --retrieval-only`（只用 BM25、沒有向量）的結果。

| 版本 | 調整內容 | 前 5 段命中率 | 含問答引用命中率 |
| --- | --- | --- | --- |
| v1 | 中文二字詞 BM25、k=5；問答引用的條文依出現順序附上前 3 條 | 65.0%（13/20） | 85.0%（17/20） |
| v2 | 問答引用的條文改依「條號附近文字與問題的重疊程度」排序，並輪流從每則問答挑選，上限 4 條 | 65.0% | 95.0%（19/20） |
| v3 | 括號註記的條號（如「慰撫金（民法第195條）」）只看前文；只用問答的「答」計算，避免問句讓第一個條號分數虛高 | 65.0% | 100.0%（20/20） |
| v4 | 數字只在「第N條」中才算詞（避免日期誤配「第10條」）；不再把單一個字當詞；加入口語→法條用語同義詞（房東→出租人、網購→通訊交易、最晚→時效…） | 75.0%（15/20） | 100.0%（20/20） |

### 典型問題與修正
- 「我 2026 年 3 月 10 日騎車被撞，最晚哪一天前要求償？」：v3 的前 5 段被日期中的「10」「年」「月」誤配到「第10條」與含日期的條文；v4 後第 1、2 名分別是「車禍求償時效」問答與民法第 197 條。
- 「民法第一百八十四條是什麼」：BM25 排不進前 5；加入「問題直接點名條號就把該條放第一」後一定命中。

## 注意事項與下一步
- 這份測試集與常見問答是同一位作者撰寫，用語相近，命中率會偏樂觀。建議請同學或家人用自己的話各寫 5–10 題加入測試集再測一次。
- 尚未評估「答案正確率」與「拒答正確率」：設定 `ANTHROPIC_API_KEY` 後執行 `npm run eval`，由 Claude 擔任評審，結果寫入 `docs/eval-report.md`。
- 設定 `OPENAI_API_KEY` 後重新 `npm run ingest`，可比較「BM25」與「BM25 + 向量（RRF）」的差異，是很好的報告素材。
- 可嘗試調整：`k` 值（`npm run eval -- --k=3`）、切塊大小（`lib/chunk.ts` 的 `CHUNK_TARGET`）、同義詞表（`lib/text.ts`）。
